# Performance Runs

Each dated child directory contains immutable harness evidence using the naming
format documented in the parent [README](../README.md). `_templates` contains
canonical artifact shapes and is not a run.

Create new run directories from the files in [`templates`](../templates). Do
not edit `run.json` or `result.json` after publishing a run. Generate
`analysis.md` through the harness; do not hand-edit generated analysis.
